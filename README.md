Fifteen replies and quotes from @rexibeh8 to make.fun's newest posts on X, each carrying make.fun and the play code, entered in make.fun's "Get the most reposts and likes on make.fun's newest X posts" bounty ($500 pot, top 50 share). The program copies POSTS.json — the list of the 15 post addresses — to the output directory, where the house reads the posts' reposts, quotes and likes.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
